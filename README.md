#Open herd tracking for shepherdless grazing
Off-grid LoRa tags and a handheld finder on Meshtastic.

##Why
Animals are released into open pastures in the morning and wander unattendedbefore returning to pens at dusk. When cattle fail to return, owners spend hoursor days searching across rugged terrain without cellular coverage.

##What
We are developing an open-source, off-grid herd tracking system built on theMeshtastic protocol. Low-power, screenless collar tags broadcast GNSS coordinatesover LoRa. A compact handheld device displays bearing and distance for livestockup to 5 km away, triggering alerts for animals that do not return at dusk.

##Status
Early stage. No code or hardware files published yet.
