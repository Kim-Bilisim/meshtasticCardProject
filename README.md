# Open Herd Tracking for Shepherdless Grazing

Off-grid LoRa tags and a handheld finder on Meshtastic.

## Why

Animals are released into open pastures in the morning and wander unattended before returning to pens at dusk. When cattle fail to return, owners spend hours or days searching across rugged terrain without cellular coverage.

## What

We are developing an open-source, off-grid herd tracking system built on the Meshtastic protocol.

Low-power, screenless collar tags broadcast GNSS coordinates over LoRa. A compact handheld device displays bearing and distance for livestock up to 5 km away, triggering alerts for animals that do not return at dusk.

## Status

Early stage. No code or hardware files published yet.
